1. **ROLLUP** is a subclause of the GROUP BY clause that allows you to calculate multiple levels of subtotals and a grand total within a single query. 
* It generates hierarchical grouping sets based on the order of the columns provided, reducing the columns from right to left.
* **How ROLLUP Works:** 

  * When you pass columns to ROLLUP(c1, c2, c3), PostgreSQL assumes a hierarchy where c1 > c2 > c3. It will automatically compute aggregates for the following combinations:

    * (c1, c2, c3) — Detailed group totals.
    * (c1, c2) — Subtotals for each combination of c1 and c2.
    * (c1) — Subtotals for each c1.
    * () — Grand total across the entire table.
* **Basic Syntax:**

  * SELECT column1, column2, SUM(column3)

&#x20;      FROM table\_name

&#x20;      GROUP BY ROLLUP (column1, column2);



  * **Examples:** 

    1. Consider a sales table containing regional sales data:

&#x20;         

|region|category|amount|
|-|-|-|
|North|Electronics|1000|
|North|Electronics|500|
|South|Furniture|1500|



&#x20;      SELECT region, category, SUM(amount) AS total\_sales

&#x20;      FROM sales

&#x20;      GROUP BY ROLLUP (region, category)

&#x20;      ORDER BY region, category;



**Expected Output:** 



|region|category|total\_sales|Explanation|
|-|-|-|-|
|North|Electronics|1000|Normal Group|
|North|Furniture|500|Normal Group|
|North|NULL|1500|North Region Subtotal|
|South|Electronics|1500|Normal Group|
|South|NULL|1500|South Region Subtotal|
|NULL|NULL|3000|Grand Total|



* **Differentiating NULLs with GROUPING():**

  * When using ROLLUP, rows containing subtotals output a NULL for the columns that have been rolled up. To avoid confusion between a natural NULL in your data and a NULL generated by ROLLUP, you can use the GROUPING() function: 

    * SELECT 

&#x20;           CASE WHEN GROUPING(region) = 1 THEN 'All Regions' ELSE region END as region,

&#x20;           CASE WHEN GROUPING(category) = 1 THEN 'All Categories' ELSE category END as category,

&#x20;           SUM(amount) AS total\_sales

&#x20;         FROM sales

&#x20;         GROUP BY ROLLUP (region, category);

* **Partial ROLLUP:**

  * If you want a grand total and specific subtotals but don't want to roll up every single column, you can leave columns outside the ROLLUP function:
  * GROUP BY region, ROLLUP(category);  -- This skips the individual category breakdown subtotals
